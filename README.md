# Welding-LEDs
Create a welding simulator for model railroad and other modeling applications  

This sketch drives several LEDs with random timers to produce a surprisingly realistic visual effect of arc welding.  It is designed to be used with model rail applications, or other scale modeling where the visual effect is required.  Cool white LEDs are triggered for random durations, with random pauses to give a very realistic appearance of stick or MIG welding. 
  
The sketch supports three, independent, welding "sites" or locations where the visual effect of welding occurs.  Site 1 and Site 2 are intended to create indirect light effects.  That is, the LEDs are not meant to be observed directly by the viewers eye.  These are commonly used inside of scale shops or buildings, and bounced off walls, or pointed at semi-opaque openings (such as frosted windows).  They give the appearance of welding, without creating a scale "arc" that is intended to be viewed directly.  Site 3 is intended to produce a realistic welding effect when observed directly.  That is, the viewer can look directly at the LEDs.  Site 3 also has a "glow" effect to simulate red-hot steel.  Site 3 uses a white LED for the welding effect, and a red LED for the glow effect.

Although the user can select any LED for the build, I recommend a cool white LED for the welding sites, and a red LED for the glow effect.  Specifically, I recommend high-intensity, 5mm, cool white LEDs for Site 1 and Site 2.  These commonly have molded lenses and can create very directional light.  Aim them at the inside of a building/shop wall that can be viewed through a window or open door.  I use the crystal clear LEDs, but diffused white LEDs can also work.  I recommend sub-millimeter "micro" LEDs for Site 3; one cool white and one red.  I use 0402 SMD LEDs that come pre-wired with pigtails.  They are incredibly bright for their size, and are essentially invisible when not lit.  You can place the red LED pretty much directly on top of the white LED so it appears the white light and red light have a single source (the location of the weld).  Pair this with a scale worker, and you will have a realistic welding operation.  

Be sure to use suitable current-limiting resistors with all LEDs.

  *What's the difference between "Welding_LEDs" and "Welding LEDs_GLOW_only"?*  

The sketch makes heavy use of timers.  All three "welding sites" are running independent (random) timers for when the arc is on, and when it is off.  Some smaller, lower performance MCUs simply cannot support so many timers and so much processing.  So while Welding LEDs supports three welding "sites" with a total of four LEDs, Welding LEDs GLOW supports only a single welding "site" with two LEDs.  The GLOW sketch uses a single white LED (to simulate the arc of a welding operation) in conjunction with a single red LED (to simulate the glow of hot steel after welding stops).  

So which boards for which sketch?  I have tested ATmega328 based boards such as the Arduino Nano and the Arduino Uno and they work fine with all three sites (the Welding_LEDs sketch).  However, I did not have success with an ATtiny88 board; it required me to fall back to GLOW_only.  Certainly any modern MCU like the ESP8266 or ESP32 is wild overkill, but it will work just fine!
